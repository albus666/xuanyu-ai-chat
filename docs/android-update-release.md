# Android 更新发布

- Android 官方 APK 在阿里云国内站点直接提供：`https://www.lingshu.uno/static/app/xuanyu-latest.apk`。不要改成 GitHub、境外构建服务器链接或反向代理。
- 更新检查接口：`/api/config/app-update`；后台「版本更新」维护构建号、版本名、更新内容及下载渠道。
- 应用启动完成和回到前台后按后台检查间隔检查版本。普通更新弹窗展示更新主要内容及「今日不再提示」，按设备当地自然日记录；跨天后允许重新检查，不需要等待完整 24 小时。
- 「设置 → 检查更新」不受今日免打扰和检查间隔限制。强制更新也不受今日免打扰限制。
- AppUpdateHost 在 MaterialApp.builder 内，必须传入根 navigatorKey，以导航器 overlay 的 context 弹窗。
- APK 必须由 xuanyu-builder.service 的远程 x86_64 流程构建，官方 APK 指定 `APP_DISTRIBUTION_CHANNEL=official_apk`。本机不执行 APK 编译。
- 构建准备只能清理独立的 remote-build-checkout，不能清理开发工作区 repo。
- 发布顺序：校验远程构建提交和 APK 版本、签名 → 上传阿里云临时文件 → 核对 SHA-256 → 保留旧包后原子替换 → 最后更新后台版本策略。不得先上调版本号再传包。
- 当前国内下载已发布版本：1.0.53 (54)，对应客户端提交 `2656562`、后端提交 `2e56634`。远程构建完成，签名与旧包一致，国内下载内容和版本策略已核验；旧 APK 与版本配置已留备份。
- 本次已发布客户端版本：1.0.53 (54)，作品直接发布、视频播放、完整房间命盘、页尾提示和入驻表单修复，并支持建群好友直接加入、简介清空、独立服务介绍和直接唤起支付，修正公开作品数量、未登录重复提示及弹层留白，并新增工作台独立名师介绍编辑，同时统一右上角三点分享入口、隐藏举报编号并改进分享弹窗按钮。本次进一步改为房间内复用四类原生专业盘，八字完整彩色表格与运限条、斗数运限切换、星盘参数按需查看，并提供独立名师名称、头像、学历、经验和介绍编辑页。新增可自行填写的其它服务类别，合并工作台资料与个人介绍入口并置顶，保存后立即同步工作台、老师主页和列表。四种命盘案例和补充资料新增账号云端同步、本地缓存、登录恢复、离线重试、删除同步和多设备冲突保护。已完成 APK 构建、版本与签名校验，国内下载文件和版本策略已同步更新。

- vivo 复核：两套注册页均要求主动勾选协议，版本冲突不再沿用勾选状态；充值页仅显示服务端已配置渠道并处理加载失败。微信支付按订单 AppID 注册后检查安装与唤起结果。生产当前只有支付宝配置就绪，真实交易、首次安装隐私动态检测和 AI 资质材料需另外验证/提交。

- 视频预览修补：发布页所选视频和作品预览页均使用本地解码画面，静音暂停于视频 0.5 秒（短视频取中间位置），点击进入实际播放器。移除、更换与退出时释放旧控制器；解码失败显示提示。组件与导航回归测试已通过，具体视频编码的手机表现仍需安装新包验证。

- 档案管理修补：星盘与七政四余改为统一档案卡片，提供搜索、分类、名称编辑、案例笔记和删除。四类命盘均允许删除本人及待补全档案，确认后同步删除关联命盘与笔记，保留账号出生资料。

- 支付与预约修补：保留微信支付入口，点击提示“上线后才可申请微信支付”，暂不创建微信订单。取消老师设置的提前小时数与统一提前 15 分钟门槛，保留未来服务时间、开放预约开关和服务时段。提交预约后通知双方，消息页定时及回到前台时刷新通知未读数。

- 通话与订单修补：好友语音/视频通话新增本地呼叫等待音与来电铃声，视频呼叫显示本机预览，按服务端 RTC 配置连接并处理重连、超时和 Token 续期。取消、拒接、未接听及结束写入双方聊天记录，挂断失败明确重试。签到仍在预约前30分钟开放，未到时间点击显示说明；双方签到后可提前开始，用户咨询页自动检查对方签到。工作台可确认删除已结束订单的本人列表记录，保留结算与售后数据。自动测试之外，真实双机音视频仍需新包装机验证。

- 消息与语聊修补：通话记录可点击按原模式重拨；私聊和群聊搜索结果返回原聊天、加载更早历史并定位高亮消息。新建群聊默认开放申请，保留明确关闭的设置。特别关心提示音使用内置音频试听，快速切换与退出避免迟到播放。语音匹配不限性别并兼容旧等待队列，保留屏蔽和未成年人限制；匹配和派对房间明确配置收音、远端订阅、播放音量和当前扬声器路由，收音或接收失败提供重试提示。真实手机双机声音仍需装机验证。
