# 案例随账号保存

四种命盘档案及案例补充资料通过 `/api/fortune/archives/sync` 保存到服务器。账号由登录会话确定，客户端不能指定他人的账号；本地 JSON/偏好按账号继续缓存，保存成功先保证本机落盘，再自动同步。登录、冷启动、回到前台和前台定时任务会恢复/重试，打开档案时也同步。

新设备的空列表只拉取，不清空云端。原有本地档案按记录 ID 上传，其他云端记录合并保留。删除留下云端版本记录，旧设备不能复活已删除记录。版本冲突保留双方内容，在档案页选择本机或云端版本；切号后迟到响应不能写入其他账号。损坏本地 JSON 不上传空列表，也不覆盖旧文件。未完成同步时显示本机保留及重试提示。

后端新增 `fortune_archive_entry` 表（`sql/migrate_fortune_archive.sql`，幂等创建，不修改已有表）。账号注销清理流程同时移除该账号的云端档案。同步内容属于账号私有档案，独立于房间授权分享。

已清除且从未上传过的历史本地案例无法由此恢复；安装新版后应先联网完成一次同步，再清除应用数据或换机。断网编辑期间同样须等云端同步完成。
