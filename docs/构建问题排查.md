# 构建问题排查

## Could not resolve io.flutter:arm64_v8a_debug / TLS handshake

若出现：

```
Could not resolve io.flutter:arm64_v8a_debug:1.0.0-xxx
> Could not HEAD 'https://storage.googleapis.com/download.flutter.io/...'
> Remote host terminated the handshake
> The server may not support the client's requested TLS protocol versions
```

**原因**：Gradle 从 Google 服务器下载 Flutter 引擎时连接失败（国内网络、代理或 TLS 限制）。

**处理方式：**

### 使用 Flutter 国内镜像（推荐）

在终端执行（当前会话有效），再构建：

```bash
# 使用上海交大 / 清华等镜像
export FLUTTER_STORAGE_BASE_URL="https://storage.flutter-io.cn"
export PUB_HOSTED_URL="https://pub.flutter-io.cn"

flutter clean
flutter pub get
flutter run
```

Windows（PowerShell）示例：

```powershell
$env:FLUTTER_STORAGE_BASE_URL="https://storage.flutter-io.cn"
$env:PUB_HOSTED_URL="https://pub.flutter-io.cn"
flutter clean
flutter pub get
flutter run
```

若在 **Cursor / IDE** 里点运行，需在 IDE 或系统环境变量里同样配置上述两个变量，否则仍会走默认 Google 地址。

### 永久配置（可选）

- **macOS/Linux**：在 `~/.zshrc` 或 `~/.bashrc` 末尾加上上面两行 `export`，然后 `source ~/.zshrc`。
- **Windows**：系统属性 → 环境变量 → 用户变量中新建 `FLUTTER_STORAGE_BASE_URL`、`PUB_HOSTED_URL`。

## JdkImageTransform / jlink 报错

若出现类似错误：

```
Execution failed for task ':shared_preferences_android:compileDebugJavaWithJavac'.
Could not resolve all files for configuration ':shared_preferences_android:androidJdkImage'.
Failed to transform core-for-system-modules.jar ...
Error while executing process .../jbr/.../bin/jlink ...
```

**原因**：Android Studio 自带的 JDK 21 与 Gradle 的 JdkImageTransform 不兼容。

**处理方式（任选其一）：**

### 1. 改用 JDK 17 构建（推荐）

安装 JDK 17 后执行（路径按本机实际修改）：

```bash
# macOS 常见路径
flutter config --jdk-dir /Library/Java/JavaVirtualMachines/jdk-17.jdk/Contents/Home
```

然后清理并重新运行：

```bash
flutter clean && flutter pub get && flutter run
```

### 2. 清理 Gradle 转换缓存后重试

```bash
rm -rf ~/.gradle/caches/transforms-3
flutter run
```

### 3. 已做的项目配置

本项目已使用 **AGP 8.7 + Gradle 8.10.2**，并在 `android/app/build.gradle` 中设置 Java 17，部分环境可规避该问题。若仍报错，请以方式 1 配置 JDK 17。

## Namespace not specified（如 amap_flutter_location）

若出现：

```
A problem occurred configuring project ':amap_flutter_location'.
> Namespace not specified. Specify a namespace in the module's build file
```

**原因**：AGP 8.x 要求每个 Android library 在 `build.gradle` 里声明 `namespace`，部分旧版 Flutter 插件未声明。

**处理方式：**

1. **项目已做自动补全**：在 `android/build.gradle` 的 `subprojects.afterEvaluate` 中已加入逻辑，对未指定 namespace 的插件从其 `AndroidManifest.xml` 的 `package` 自动补全。先执行 `flutter clean && flutter pub get && flutter run` 重试。

2. **若仍报错，可手动改插件**：在插件目录的 `android/build.gradle` 里，在 `android { }` 块中增加一行 `namespace '...'`（包名与插件 `AndroidManifest.xml` 里 `package` 一致）。例如 amap_flutter_location 可改为：

   - 打开：`<pub-cache>/hosted/pub.flutter-io.cn/amap_flutter_location-3.0.0/android/build.gradle`
   - 在 `android {` 下一行添加：`namespace 'com.amap.flutter.location'`

   注意：`flutter pub get` 或升级依赖可能覆盖修改，必要时可考虑换用已支持 namespace 的插件版本或 fork 后修改。
