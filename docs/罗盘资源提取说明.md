# 从反编译 APK 提取罗盘资源

`base_out` 来自对 **base.apk** 的反编译，但当前解出的目录里**没有**罗盘/八卦的图片文件（只有 `AssetManifest.json` 里列了名）。要拿到原版罗盘资源，需要从**完整 APK** 里解压。

## 步骤

1. **准备 base.apk**
   - 从你的备份或应用安装目录拿到 `base.apk`（与 base_out 同一次构建的版本更稳妥）。
   - 若用的是 App Bundle，可从 `*.aab` 里解出 base 模块，或从已安装设备用 adb 拉取 base.apk。

2. **执行提取脚本**
   - 把 `base.apk` 放到项目根目录 `XuanYu/` 下，然后执行：
     ```bash
     chmod +x scripts/extract_luopan_from_apk.sh
     ./scripts/extract_luopan_from_apk.sh
     ```
   - 或指定 APK 路径：
     ```bash
     ./scripts/extract_luopan_from_apk.sh /path/to/base.apk
     ```

3. **结果**
   - 脚本会把 APK 里的 `assets/flutter_assets/assets/luopan/`、`assets/bagua/`、以及首页罗盘相关图标解压到本项目的：
     - `assets/luopan/`（罗盘图标、罗盘样式图 1.png～4.png 等）
     - `assets/bagua/`（64 卦图、default_ba_gua.png、gua_overview.json）
     - `assets/home/`（home_luo_pan_icon.png 等）

4. **使用**
   - 电子罗盘页会优先使用 `assets/luopan/luo_pan_style/1.png` 等作为罗盘底图（若存在），否则继续用现有的 `assets/baguapan/compass.png` 或占位图。

## 若没有 base.apk

- 若只有 base_out，拿不到原 APK，则无法从 APK 里抽出这些资源，只能继续用当前项目的 `baguapan` 罗盘（compass.png + taiji.png + 占位）。
