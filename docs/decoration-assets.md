# 装扮中心主题素材

使用内置 image_gen 工具生成原创背景，未复制参考视频中的图案。运行时的光点由 Flutter 绘制，PNG 本身为静态底图；人物眨眼等逐帧动画不包含在这些 PNG 中。

目录：`assets/decorations/`。首屏优先晴空、奶油、薄荷色，深色月夜作为可选风格。
