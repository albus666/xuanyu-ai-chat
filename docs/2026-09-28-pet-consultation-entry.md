# 寻宠顾问“先私聊”入口修复

状态：灵宠心语及寻宠咨询已按用户要求从当前客户端移除。本文为历史修复记录。

## 已复现

在真实 `PetSearchConsultationTab` 上拦截全部 HTTP、禁用真实认证与 WebSocket。10 项基线测试中 8 项失败、2 项正常通过：

- 文案明确“先私聊，再决定是否付费咨询”，按钮实际调用旧收费开通接口 `single-with-master`。
- 顾问列表业务错误、格式错误被当成暂无顾问，无法重试。
- 私聊业务失败但附带 ID，或返回 0 号会话，仍打开聊天。
- 切号后旧按钮仍可发请求；迟到私聊成功仍跳转，迟到列表仍显示旧数据。
- 原有快速重复点击防护、成功空列表是正常对照用例。

## 修改边界

- “先私聊”接回普通 `/api/im/conversation/single`；独立“付费咨询”仍进入老师详情，不调整收费标准、咨询价格或普通私聊准入规则。
- 使用既有 `ImWorkflowRequest` 固定账号/认证，校验业务状态与列表格式。切号立即清除页面数据，旧操作、响应和导航失效。
- 加载按请求序号处理，最新请求优先；失败显示原有错误区和重新加载按钮。私聊失败明确提示，正整数会话 ID 才能进入。
- 不修改老师详情/支付规则；不清理历史扣费，不读取或操作真实钱包。

## 验证与未验收

专项测试：`test/features/pet_insight/pet_consultation_entry_test.dart`，修复后 10/10 通过；加上灵宠页面 360/430 宽布局检查，共 12/12 通过。最终合并执行结果在本批总报告中记录。

模拟接口覆盖的是 UI、请求路径和竞态，不等于真实双端或支付链路验收。退款或历史账务核对必须另行授权。
