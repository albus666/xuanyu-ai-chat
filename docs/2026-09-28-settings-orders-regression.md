# 第二部分：设置、订单与资料库回归（2026-09-28）

## 已复现并修复

1. 设置缓存未分账号，切换账号沿用上一人的隐私选项。现在按用户 ID 分开，字号与减少动效保留设备偏好；旧的无归属隐私缓存不迁移给新账号，服务端原设置不变。
2. 旧账号迟到的设置响应覆盖新账号。增加会话隔离，未发出的旧设置也不借用新账号发送。
3. 连续修改设置时，一项失败回滚整个设置、撤销另一项成功结果；旧刷新也可能覆盖新修改。现在串行提交、按字段回滚到最后确认值，并忽略过期刷新。
4. 隐私读取失败仍允许提交默认值。未成功读取时禁用保存、隐藏未读取项并提供重试；社交设置请求失败不丢弃已读到的主页隐私，重试不重置用户已编辑的主页选项。
5. 隐私开关保存失败后显示未及时恢复。页面订阅设置变化，保存失败即恢复；主页隐私保存期间禁用相关开关。
6. 快速切换订单筛选时旧结果覆盖当前分类，分页期间切换被忽略。请求绑定分类、页码、会话与序号，最新请求才更新列表；切号清理旧列表。
7. 订单分页失败没有提示。保留已有条目、显示重试入口，失败不跳页，跨页重复订单去重。
8. 资料条目点击反馈被外层背景遮挡，界面测试触发 Material 层级断言。为资料条目补充独立 Material 绘制层，不改布局或权限。
