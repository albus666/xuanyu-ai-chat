# 通话浮窗、余额时长及派对赠礼

- 语音匹配缩小图标统一为四角收拢，缩小返回主页并保留音频；关闭匹配页不再取消交给浮窗的通话。
- 移除双头像之间的横线，挂断按钮及浮窗拖到底部均需确认。
- 匹配与专线浮窗统一为 60 像素，使用全局拖动坐标和稳定组件 key 保持连续手势。
- 已结束的专线不能再次最小化成悬浮图标；浮窗中远端结束会清除浮窗。
- 老师进入 waiting 专线先调用幂等接听接口，再加入 RTC；等待文案按角色区分，全局来电层在当前通话结束后继续接收新预约。
- 名师语音房改用 meeting 音频场景，明确关闭耳返并启用 AEC/ANS/AGC。瞬间碰撞、关门等回音仍需双手机实测。
- 后端新增 walletRemainingSeconds，计算可用钱包余额加当前专线未用完的预留款。remainingSeconds 继续用于滚动预留和安全扣费，不改变计费。
- 用户余额不足两分钟显示充值入口，并发出一次带充值按钮的提示；充值后恢复提醒能力。
- 生产派对消息 content 为 VARCHAR(500)，包含礼物动画地址的 JSON 超限导致赠礼 500。新增幂等命令 expand_room_message_content 扩为 TEXT，保留已有数据；新建表同步使用 TEXT。
- 赠礼重试沿用原请求键，禁止重复扣币。未执行任何真实赠礼交易。
