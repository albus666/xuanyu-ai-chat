# 四个需求实现说明

## 1. 真人名师（已完成）

- **单独付费**：咨询名师前从用户余额扣费，单价由后台配置，默认 10 元。
- **后台控制单价**：执行 `server/sql/migrate_teacher_consult_price.sql` 增加 `user_profile.consult_price`；管理后台「名师认证审核」→ 已通过 → 可设置每位名师的「咨询单价」并保存。
- **名师简介**：名师列表与详情已展示 `intro`（来自 `user_profile.intro`）。
- **交流页显示用户资料**：聊天页标题可点击进入对方「用户资料」页；与名师单聊时显示「名师」标识。
- **名师独特标识**：真人名师列表与聊天页标题旁显示「名师」角标。

接口说明：
- `GET /api/community/masters` 返回 `consultPrice`。
- `POST /api/im/conversation/single-with-master` body: `{ targetUserId }`：无会话则扣费后建会话，已有会话直接返回。
- 管理后台 `POST /api/admin/teachers/<user_id>/consult-price` body: `{ consultPrice: 10 }`。

---

## 2. 分享：微信朋友圈 + APP 外部分享（已完成）

- 点击帖子「分享」后弹窗可选：**分享给好友**（站内）、**分享到微信、朋友圈等**（`share_plus` 调起系统分享面板，可选微信/朋友圈等）、**分享图（带 APP 二维码）**（见下）。
- 外部分享文案为：`【玄遇】` + 内容摘要 + `打开玄遇 APP 查看详情`。

---

## 3. 用户作品互动：评论回复 + 删除 + 转发收藏（已完成）

- **评论回复**：已有（`parentId` 回复、列表展示层级）。
- **评论删除**：后端 `POST /api/community/post/<post_id>/comment/<comment_id>/delete`（仅评论作者或帖子作者可删）；详情页每条评论/回复旁对本人或帖主显示「删除」并二次确认。
- **收藏**：已有；**转发**：站内「分享给好友」即转发给关注的人。

---

## 4. 外部分享标识：带 APP 二维码（已完成）

- 分享入口增加「分享图（带 APP 二维码）」：生成含帖子摘要 + APP 名称 + 二维码的卡片图，可分享到系统（微信、朋友圈等）。
- 二维码内容由 `AppConstants.appDownloadUrl` 或 `appNameForShare` 决定；落地页 URL 可在 `app_constants.dart` 中配置。
