# 2026-09-28 使用问题修复与验收范围

## 本轮修复

1. 斗数、星盘、七政四余档案不再在第 51 条时截掉旧档案及笔记。旧版本已经删除的数据不会自动恢复。
2. 聊天慢网发送成功后，不清空用户继续输入的下一条草稿。
3. 聊天历史使用消息 ID 游标分页，支持上翻加载与失败重试。
4. WebSocket 重连、应用回前台主动补消息；刷新中的新通知会追加刷新，离线超过 50 条也能补齐。
5. 阅读历史不再被新消息强制拉到底部，显示“有新消息”入口；旧快照不覆盖刚发送成功的消息。
6. 房间案例缺少性别或出生地时可以当场补全并查看专业盘面，补充信息按账号及源档案 ID 保存。
7. 超过 2000 个字符明确提示并保留草稿，服务端拒绝而非静默截断。
8. 退出登录、切换账号或修改密码前，先走语音房原有退出确认和服务端退出流程；取消/失败不切号。登录失效时移除旧账号悬浮房间。
9. 旧会话迟到的 401 不再退出新账号或清除其缓存。
10. 图片上传与文字发送并发时不丢图；图片发送失败保留占位并可重试，成功上传的文件不重复上传。
11. 同名同生日但性别、地点或时区冲突的案例不合并；同类型不同档案不覆盖，跨盘种资料一致仍互通。

## 验证边界

- 本轮定向 Flutter 回归 42 项通过；19 个相关代码/测试文件静态检查无问题。
- 后端独立测试 3 项在本机及生产服务器均通过；生产服务已更新至 `7740c91`，重启后服务、MySQL、Redis 健康检查正常，近期服务日志无错误。
- Flutter 页面交互、模拟慢网/失败接口、账号隔离和临时档案读写均使用隔离数据，不向真实用户发消息。
- 后端独立测试使用模拟数据库操作，不接触生产聊天、订单、余额或档案。
- 目标版本：`1.0.11+12`。前端修复需要安装包含本次提交的新版本才会生效。
- 仍需真机：双账号双机收发、真实图片选择器权限、断网重连、前后台麦克风释放、付费房间退出与结算。服务端健康检查及自动化测试不能替代这些验收。
- 本轮不是全 APP 的无缺陷保证；未调整支付规则、未移除内容审核，也未执行真实交易或资料删除。
