# 个人主页、收藏与关系入口定向回归

日期：2026-09-28；全 APP 排查第三批第三段；目标版本：`1.0.15+16`。

## 确认的问题与修复

1. 先用界面测试复现：公开主页网络错误被显示成“用户不存在”；本人主页刷新后，未完成的旧第一页继续追加进新列表。现在区分网络错误/权限限制/真实不存在，有重试入口；本人资料失败不再无限转圈。
2. 测试同时复现了公开主页 Sliver 标签栏的 `layoutExtent exceeds paintExtent` 异常：声明高度 46，原实际高度 45。固定实际容器高度，保留原来的资料卡、背景手势和标签设计；360/430 宽度验证通过。
3. 统一作品、收藏和赞过列表分页状态。刷新取代旧请求；迟到的旧响应、异常或 finally 均不能改写新请求状态。按作品 ID 去重，下一页失败不跳页，刷新失败保留原内容且重试第一页，异常响应不当作空列表。
4. 错误期间不自动反复重试；短列表提供“加载更多”，失败有“重试加载”。空页即使误报还有下一页也停止加载。刷新本人主页保持当前标签，详情页返回刷新当前列表并使其他标签旧缓存失效。
5. 账号切换立即清除本页私有列表、资料和关系状态，旧请求不可回写。退出页面后响应不通知已销毁组件。本人 IP 归属地补全固定会话，切号后不得把旧查询结果写进新账号。
6. 关注接口实际为 toggle，增加请求中防重复；只有服务端业务成功才改变状态和本地粉丝数；取关仍保留确认。旧资料刷新不能覆盖关注结果。
7. 拉黑确认与请求统一防重复；确认期间切号就停止后续动作；业务失败保留主页并提示，成功才清空主页并尝试返回。
8. 私聊入口防重复创建/导航，业务失败允许重试，切号后旧会话响应不再打开聊天。点赞结果按作品 ID 更新，列表刷新替换作品后失败不再按旧下标回滚而误改其他作品。主页点赞与悄悄关注同时补上响应校验、失败提示和旧会话结果保护。
9. 独立收藏页错误可重试；取消收藏成功后立即移除并重查第一页，避免集合变小后偏移分页漏掉下一项；删除回调只刷新本页，不新增删除业务。第三方分享回调不能修改切号后的列表。
