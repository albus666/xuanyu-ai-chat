# 礼物发送与特效专项

日期：2026-09-29（UTC）。用户同意一起完善礼物功能和展示。本轮保留现有 PNG/MP4 美术素材，没有重新制作动物动作视频，不将代码回归称为真机视觉验收。

## 修改范围

- 发送面板在确认弹窗之前锁定操作；明确显示接收者，允许独立预览，预览不调用赠送接口。
- 数量统一为 1～999；确认金额、实际请求金额与服务端成交价校验一致，四位小数不在确认文案中误舍入。
- 每个账号、每个聊天/房间独立持久化待确认的固定赠送请求；网络超时、5xx、异常成功回执不换新请求号。关闭后重新打开仍核对同一笔，不能改数量或对象后误重送。读取损坏记录时保留原文并阻止新单。
- 页面、读取、确认和写入固定登录会话；切账号后清空旧内容、关闭旧确认和预览，不将迟到结果交给新账号。
- 服务端按发送账号行锁串行处理重试，锁定读取已存在订单并核对完整意图；价格变化需要再次确认；正常回执、重复回执和消息统一订单与双方身份字段。补聊天实时刷新事件。
- 私聊、群聊和语音房间接收新礼物均进入播放队列；初次历史不重播，同一订单 API 回执与消息回流不重复播放；队列有界，退出/切号清空。
- 连续同双方、同礼物的不同订单仅在等待队尾合并展示，最多 10 连击；不改变实际订单、聊天记录或正在播放的礼物。
- 特效结束由播放器实际完成或用户跳过驱动；初始化超时、解码错误和播放停滞可降级，不用送出时刻起算的父级计时器提前移除。
- 视频局部展示并保持主体比例；小礼物轻量透明，显示赠送双方、数量与连击；系统/应用减少动态效果时显示短静态提示；保留房间入场特效兼容。
